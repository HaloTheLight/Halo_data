# 🏆 프로젝트 HALO: 야간 보행자를 위한 실시간 시공간 위험도 예측 내비게이션

**Team:** Los Algorithm  
**Role:** ML Data Engineer (데이터 파이프라인 구축 및 ML 피처 설계)

---

## 📍 1. 문제 정의 및 솔루션 방향 (Problem & Approach)
* **기존 내비게이션의 한계:** 오직 '시간(Speed)' 최적화에만 집중되어 있어 심야 시간대 보행자의 '안전'에 대한 우려를 해결하지 못합니다.
* **기존 범죄 지도의 한계:** 단순한 과거 발생 기록(Incident maps)만 보여줄 뿐, 당장 어떤 길을 선택해야 하는지에 대한 실시간 가이드를 주지 못합니다.
* **HALO의 해결책:** 단순한 속도가 아닌, **'현재 관측된 환경 조건(Observed conditions)'**을 기반으로 도로의 점수를 매겨 최적의 안전 경로를 안내하는 모델을 기획했습니다.

## 🏗️ 2. 대규모 시공간 데이터 파이프라인 구축 (The Data Foundation)
* **이질적 데이터 통합:** 범죄 기록, 311 시민 신고, 가로등 고장 내역 등 5가지 이질적인 공공 오픈 데이터를 수집하여 하나의 뼈대로 결합했습니다.
* **정밀한 공간 맵핑 (Spatial Join):** Python과 GeoPandas를 활용해 50미터(50m) 공간 버퍼 조인을 수행하여, 데이터를 **195,320개의 실제 보행자 도로 세그먼트(Walkable street segments)**에 정밀하게 매핑했습니다.
* **대규모 학습 패널 구축:** 시간대와 요일을 세분화하여 머신러닝 학습에 즉시 투입 가능한 **6,250만 행(62.5 Million Rows)** 규모의 거대한 시계열 학습 패널을 구축했습니다.

## ⚖️ 3. 동적 위험도 스코어링 및 데이터 윤리 (Dynamic Risk Scoring & Ethics)
* **동적 가중치 산출:** 도로의 안전 점수를 산출하기 위해 `사건 위험도(42%)`, `조명(31%)`, `유동성(19%)`, `안전 거점 접근성(8%)`의 가중치 방식을 설계했습니다. 이 점수는 고정된 값이 아니라, 시간대의 변화나 가로등 고장 등 **도로의 상태 변화에 따라 동적으로 변환**되도록 구현했습니다.
* **데이터 윤리 (Data Ethics):** 윤리적 기준을 엄격히 적용하여 노숙자 텐트(Encampment) 관련 신고 데이터는 예측 모델에서 완전히 배제했습니다.
* **객관성 확보 원칙:** 특정 지역을 임의로 '안전하다/위험하다'고 단정 짓지 않고, 오직 **'데이터로 측정된 환경 수치'**만을 객관적으로 제공하는 원칙을 수립했습니다.

## 🛡️ 4. 타겟 누수 방어 및 ML 모델 성능 검증 (Leakage-Safe by Design)
* **타겟 누수(Target Leakage) 원천 차단:** 시계열 예측 시 모델이 미래의 데이터를 미리 훔쳐보는 것을 방지했습니다. 이웃 도로의 특성(Neighbor features)을 예측 변수로 사용할 때, 오직 과거 기간(Past periods)의 데이터만 참조하도록 **엄격한 시간적 장벽(Temporal Divide)**을 설계했습니다.
* **미본적 지역 테스트:** 모델이 단순한 과거 위치를 암기한 것이 아니라 '사건 주변의 환경적 조건(Conditions)'을 성공적으로 학습했음을 증명하기 위해, 학습에 사용되지 않은 미본적 지역(Unseen districts)에 테스트를 진행했습니다.
* **성능 결과:** 과적합(Overfitting) 없이 전체 모델 기준 **AUC 0.94**의 높은 정확도를 달성했습니다.

## ⚡ 5. 실시간 라우팅 아키텍처 및 UI (Instant by Design & User Choice)
* **Pre-compute 아키텍처:** 복잡한 공간 조인과 위험도 점수 계산을 백엔드에서 미리 수행해 두는 아키텍처를 설계했습니다.
* **Zero-Latency API:** 이를 통해 앱에서 API 호출(Lookup) 시 지연 시간(Waiting) 없이 실시간으로 즉시 경로를 반환할 수 있도록 시스템을 최적화했습니다.
* **사용자 선택권 보장:** 사용자는 앱을 통해 **1) 가장 빠른 길(Fastest)**, **2) 균형 잡힌 길(Balanced)**, **3) 최적의 환경(Best conditions)**이라는 3가지 경로를 블록 단위로 확인하고, 본인의 우선순위에 맞춰 직접 경로를 선택할 수 있습니다.
